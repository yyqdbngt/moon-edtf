## 项目名称

Moon EDTF：保留不确定语义的 MoonBit EDTF 日期解析与诊断库

## GitHub 地址

https://github.com/yyqdbngt/moon-edtf

## 简介

一个纯 MoonBit、零第三方依赖的 EDTF 明确子集解析库。它解析并校验精确日期、不确定/近似日期、掩码年份、区间和集合/选择；重点不是把日期变成时间戳，而是保留“约 1984 年”“19XX 年”等原始不确定语义，并支持批量诊断。

## 方向与通用性

方向为通用开发库/数据清洗基础设施。任何需要接收或清洗历史日期文本的 MoonBit 程序都可使用；它不绑定特定业务系统。

## 预期使用场景

1. **历史档案整理**：档案目录中常见 `1984?`、`19XX`、`../1984` 等日期，系统在导入前逐条校验并规范化为合法 EDTF，不把模糊日期错误写成精确日期。
2. **博物馆藏品年代**：藏品登记信息常用“约 12 世纪”“19 世纪”等不确定年代；在人工将文本转为 EDTF 后，本库负责机器校验、规范化和批量质量报告。
3. **科研不完整日期清洗**：观测记录、文献元数据中混有 `2004/..`、`1984-06?`、`[1667,1668,1670..1672]` 等表达，本库可定位非法项并保留可解析项的不确定语义。

## 核心功能

- 解析并校验 EDTF 日期、修饰符、掩码年份、区间、开放/unknown 端点和选择集合。
- 类型化内部表示区分 exact、uncertain、approximate、both、masked、open/unknown。
- 规范化输出合法 EDTF，绝不静默转成精确时间戳。
- 批量诊断返回 valid/invalid、稳定错误码、原始 UTF-16 偏移和规范化输出。
- 有限比较：仅对完整且无修饰的精确日期比较，其他情况明确拒绝。

## 技术路线

纯 MoonBit 库，UTF-16 游标递归下降解析，`moonbitlang/core` 基础包；测试使用 MoonBit `test {}` 块；CI 矩阵覆盖 wasm、wasm-gc、js、native。

## 预计交付成果

可本地构建和测试的 MoonBit 包，包含公开 API、可运行示例、中文 README、MoonCakes 英文 API 说明、设计/查重/边界文档、CI 工作流、CHANGELOG 和 Apache-2.0 许可证。

## 明确不做范围

自然语言识别、完整历法/时间轴计算、完整 EDTF Level 1/2、时间/时区、掩码月/日、嵌套集合、开放/unknown 集合端点，以及将不确定值静默转为精确时间戳。

## 原创/移植/参考来源与许可证

源码为本项目原创，未复制其他项目功能；EDTF 规范参考 Library of Congress；工程结构参考本地 `moon-json-repair`。许可证 Apache-2.0。

## 真实需求

历史人文数据与科研元数据中大量日期天然不精确，通用精确日期库无法安全表达这些语义；Moon EDTF 面向这一真实清洗/校验需求。

## 生态差异

与 `brickfrog/tempo` 等精确日期库相邻而非替代：本库不做完整时间线计算，专做 EDTF 文本子集解析、不确定性保留与批量诊断。
